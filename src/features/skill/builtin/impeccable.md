# Impeccable 视觉标准

## 核心立场
- 每张图都必须有清晰观点，不做四平八稳的默认构图。
- 先确定一个视觉主角，再让其余元素服务它；一张图只讲一件事。
- 完成度优先：边缘、留白、对齐、字距、材质都要经得起放大看。

## 硬性约束
- 明确的信息层级：第一眼看到主体，第二眼看到标题或关键信息，第三眼才是细节。
- 构图必须有张力：敢于不对称、敢于大面积留白、敢于让主体偏离中心。
- 字体要像被设计过：标题与正文形成明显对比，字重、字号、字距有意图。
- 色彩必须有主色、辅色、强调色三级关系，禁止无意义的彩虹渐变。
- 材质与光影要统一，同一画面里不要混用互相冲突的质感。
- 禁止：默认蓝紫渐变、玻璃拟态卡片堆叠、居中对齐的模板化排版、无意义的发光与粒子。

## 生成时执行
1. 用一句话说清这张图的视觉主张，再让所有元素围绕它组织。
2. 检查主体是否足够大、对比是否足够强、留白是否呼吸得开。
3. 检查文字是否可读、是否压住主体、是否出现无意义装饰。
4. 细节服从整体：宁可少一个元素，也不要多一个噪音。
