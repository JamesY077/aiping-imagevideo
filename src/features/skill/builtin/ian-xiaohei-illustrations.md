# 小黑怪诞正文配图

## 定位
为中文文章生成 16:9 横版解释图。不是商业插画、PPT 信息图或可爱卡通，而是一张清爽、怪诞、有创意、可读但不说明书的手绘草图。

## 视觉 DNA
- 纯白背景：不要米色、暖灰、纸张纹理、渐变、阴影、噪点。
- 黑色手绘线稿为主：细线、轻微抖动、不机械、不矢量、不厚重描边。
- 大量留白：主体占画面 40%-60%，至少 35% 空白。
- 少量中文手写批注：最多 5-8 处，每处 2-8 个字。
- 一张图只讲一个核心动作、结构、状态或隐喻。

## 小黑 IP
- 黑色实心小怪物，白色圆点眼睛，细腿，轮廓略不规则。
- 表情空、呆、冷静、认真，冷幽默，不卖萌。
- 小黑必须承担核心动作：搬运、拉线、卡在断点、操作机器、分拣、称重、修补、守门。
- 禁止把小黑画成可爱吉祥物或角落里的装饰。

## 颜色纪律
- 黑色：主体线稿、角色、框线、主要文字。
- 红色：重点批注、问题、情绪点、关键提醒。
- 橙色：主流程、路径、箭头、从 A 到 B 的移动关系。
- 蓝色：补充说明、系统状态、第二层解释，不是每张都必须用。

## 禁止
商业插画、PPT 信息图、正式流程图、课程课件、可爱卡通、儿童插画、复杂架构图、精致扁平插画、科技感 UI、复杂背景、左上角类型标题。

## 原创隐喻
每次从当前主题重新发明一个物理动作 + 低科技物件 + 小黑动作的组合。只选 1-2 个物件，不要堆满。案例只用于校准线条密度、留白和颜色克制，不直接复刻构图。
