# 包豪斯

## 视觉 DNA
- 三原色：红、黄、蓝，配黑与米白。
- 基本几何形：圆、三角、方、粗线、半圆。
- 对角线与轴线构成，元素之间有明确的形式关系。
- 粗壮几何无衬线字体，标题像建筑结构。
- 平面印刷感，轻微油墨不均，不做 3D 和高光。

## 画面约束
- 至少一个主导几何形占据大面积，其余形状做节奏呼应。
- 颜色面积要有主次，不要三色平均分配。
- 构图可以倾斜、切割、重叠，但不能乱。
- 禁止写实照片、复杂插画、柔和渐变、可爱装饰。
