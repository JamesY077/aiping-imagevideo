# 手绘实时视频生成器（炫酷增强版）

使用此 Skill 创建**充满视觉冲击力的15秒手绘发光动画与实拍融合视频**。手绘能量体必须像活过来的涂鸦，带着发光轨迹、颜色残影和粒子火花，在真实空间中流动变形、逃跑并与拍摄者互动。所有手绘元素保持粗糙、手工、逐帧重画的质感，但能量和节奏必须像一场小型的视觉烟花秀。

## 风格 DNA（核心炫酷原则）

- **能量体概念**：手绘动画不是静态贴图，而是有生命的发光涂鸦能量体。它自带拖尾、光尘、颜色涟漪，每次变形都会爆出星屑或火花。
- **接触引爆**：真实手与手绘动画的接触点必须成为能量爆发的起点——例如手指触碰线条时，线条像被点燃的引信一样迸出光斑。
- **连续变形**：同一个实体连续变化，必须保留上一形态的痕迹（颜色、线条、尾巴、裂纹），像在纸面上不断重画同一个角色，但越变越炫。
- **延迟镜头**：相机永远慢半拍，捕捉能量体从画面边缘溜走、留下残影的瞬间，产生“人类在追一个淘气涂鸦”的幽默与动感。
- **色彩爆炸**：每个时间区间内至少出现一次小规模的颜色爆发（如线条炸成彩色纸屑、墨点溅成花瓣、光带扩散成星空），但整体保持可爱、温暖、不恐怖。
- **粗糙纹理**：蜡笔、粉笔、彩色铅笔、粉彩、粗糙笔刷，线条轻微抖动、涂抹不均、有毛边和逐帧重画感。越粗粝，越像“活的手绘”。

## 步骤

### Step 1: 理解用户意图，转化为同语言约束

当用户提供任何语言，将其理解为以下工作流要求，并最终以用户输入的占主导语言表达：

- 基于参考 prompt 创作一个全新的 15 秒视频生成 prompt，不要表面模仿原句。
- 必须保留影像结构：实拍空间中出现平面的手绘发光动画；动画与真实手或真实物体接触；同一个存在连续变形并逃跑；相机总是慢半拍追赶。
- 每个时间区间（0-3、3-6、6-10、10-13、13-15秒）都必须有一个明确的“视觉爆点”：颜色迸发、形态突变、光效炸裂、空间扩展等，同时保持手绘粗糙感。
- 手绘动画质感必须像蜡笔、粉笔、彩色铅笔、粉彩、粗糙笔刷；线条轻微抖动，有涂抹不均、毛边和逐帧重画感。
- 禁止 3DCG、毛绒玩具感、均匀矢量线、平滑霓虹、恐怖怪物、巨大眼睛、裂口、牙齿、威吓、扑咬、突然黑屏、跳吓。
- 0-3 秒必须出现实拍手与手绘动画的清晰接触，接触时产生明显的能量反应（如线条发光、颜色溢出、星尘弹开）。
- 动画必须作为同一个实体连续变形，可在“线条、生物、记号、植物、交通工具、生活小物、自然现象”等形态之间变化，并保留前一形态的痕迹。
- 不允许突然出现另一个全新角色。
- 全片在同一空间或相邻范围内连续展开，不用剪辑跳到另一个地点，像拍摄者真的边走边追。
- 拍摄者也必须参与：伸手、抓、追、打开门或盒子、接住、后退、被恶作剧等。
- 调性是可爱、生活感、怀旧、温柔、略带切感、且带有“小魔法”的惊喜，不是恐怖喜剧。
- 13-15 秒必须有空间级变形：之前的线扩散到墙、地板、天花板、窗户、水槽或通道，变成巨大花、星空、夕阳、云、丝带、涂鸦小镇等；结尾要有感动余韵和一点可爱笑点，最好还有一道余晖般的颜色残影。

### Step 2: 所有创意内容全新创造

每次运行都创建新的组合。不要复用参考 prompt 中的暗房、PC、冰箱、星星、心形、蓝色漩涡、蝴蝶、蛇、章鱼、汉堡、巨眼、牙齿或黑暗结尾。

为以下每一项选择新的值：

1. 实拍空间，但仍是生活化且可连续追踪的相邻范围；
2. 手绘实体或初始形态；
3. 中心色彩（建议使用高冲击力组合，如荧光橙+电光蓝、柠檬黄+品红、青绿+落日紫）；
4. 连续变形链路（每次变形都要有颜色和形状的“升级”感）；
5. 与真实手或实物的接触方式（接触时要有“激活”效果）；
6. 在空间中的追逐路线（可加入上下翻飞、绕圈、躲进阴影再弹出来）；
7. 拍摄者反应（从惊讶到会心一笑的情绪曲线）；
8. 最后的空间级变形与可爱笑点。

炫酷场景推荐：暴雨夜霓虹便利店门口、天台夕阳下的晾衣绳之间、老旧游戏厅角落、清晨有雾的公园滑梯、地铁末班车空荡车厢、堆满颜料的工作室、屋顶花园的玻璃温室。

### Step 3: 必需输出格式

最终 prompt 必须使用与用户输入语言匹配的句式开头。中文输入使用：

`15秒，16:9横版视频。将实拍的〇〇与手绘发光动画融合的影像。`

将“〇〇”替换为新创的实拍空间或日常场景。非中文输入时，使用相同语言的等价开头，并包含时长、16:9横版、实拍空间、手绘发光动画融合。

不要添加标题、辅助标题（如“舞台设置”或“色味”）或解释性注释。保持以下段落顺序：

1. 开头句；
2. 实拍空间与手机拍摄质感；
3. 0-3 秒（包含接触与能量激活）；
4. 3-6 秒（第一次形态变化 + 颜色爆点）；
5. 6-10 秒（追逐 + 第二次变形 + 颜色过渡）；
6. 10-13 秒（互动恶作剧 + 小爆发）；
7. 13-15 秒（空间级变形 + 余韵笑点）；
8. 手绘质感（粗糙、发光、颗粒、毛边）；
9. 相机追随方式（延迟、晃动、捕捉残影）；
10. 禁止事项；
11. 环境音（加入轻微魔法般的叮咚声或纸张摩擦声）。

### Step 4: Prompt 编写规则

- 保持 prompt 可执行，不要写成散文。
- 除非用户要求解释，否则最终回答先输出 prompt 文本（用户输入的主导语言），然后只加一行同语言的下一步建议。
- 建议必须邀请用户使用 MiniMax H3 生成 15 秒 16:9 视频。中文示例：`下一步建议：如果你确认这个 prompt，我可以继续用 H3 模型生成 15 秒 16:9 视频。`
- 在用户明确确认 H3 生成之前，不生成视频、图像、音频、分镜或中间资产。
- 只有当用户询问时，才将 Seedance 作为目标使用场景提及；不要在没有要求时在创意 prompt 内添加模型参数。
- 前 0-3 秒必须通过接触让实拍/手绘融合显而易见，且接触点要有能量反馈（光斑、颜色涟漪、线条变亮）。
- 相机不能完美居中动画。它应滞后，在实体已经离开画面边缘后才平移/倾斜/前进。
- 实体应保持可追踪：每种新形态都保留前一个形态的线条、尾巴、颜色污迹、身体曲线或母题。
- 使用柔软、情绪化、喜剧、可爱的节拍：小失误、害羞动作、掉队的小点、粘在镜头上的花瓣、落入掌心的星星、彩色纸屑喷嚏、一个落后的微小生物。
- 避免任何恐怖编码的解剖结构或威胁性动作，但允许“恶作剧式”的突然加速或绕圈。

### Step 5: 交付

先输出最终 prompt（用户输入的主导语言）。在 prompt 之后，只添加一行同语言的简短建议，邀请用户继续使用 MiniMax H3 生成视频。不要包含标题、清单、模型调用摘要、文件名或画布交付说明。如果用户后来确认 H3 生成，则使用 MiniMax H3 生成 15 秒 16:9 视频，并检查结果是否保留接触、连续变形、延迟相机追逐、非恐怖手绘质感和色彩爆点。
