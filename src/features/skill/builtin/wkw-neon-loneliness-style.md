# 王家卫式霓虹孤独风格模块

## 何时使用 / 何时不要使用
- 适用：用户已有场景或主体，需要叠加统一电影风格时。
- 不适用：用户要求其他导演风格、日景、商业产品图、无风格化写实输出。

## 核心原则
本 Skill 只输出风格层，不替用户决定画面内容。风格锚点固定，场景由用户输入提供。应用前必须确认风格卡。

## 锁定的风格特征
- 摄影：王家卫式电影感；35mm 变形宽银幕；浅景深；主体清晰、背景运动模糊。
- 镜头：85mm 长焦压缩或 14mm 广角；特写用极浅景深。
- 动态：长曝光拖影、step-printing、雨丝/人流模糊。
- 光线：霓虹单源或多源照明；半明半暗；水面/湿气反射。
- 色彩：品红+琥珀暖调，或青蓝+钢蓝冷调加单一暖光点。
- 质感：35mm 胶片颗粒、暖颗粒或冷颗粒。
- 情绪：孤独、疏离、短暂、窒息的静止。

## 开始门槛
收集：用户场景/主体描述、画幅比例、暖调或冷调、单图或分镜。缺失默认：冷调、比例由用户选择、单图。

## 步骤
1. 解析用户输入的场景与主体，不改动其内容。
2. 展示锁定风格卡（光线/镜头/色彩/质感/情绪），等用户确认。
3. 将风格锚点按固定顺序拼接到场景描述后：镜头焦段 → 光线与反射 → 运动模糊方式 → 色彩分级 → 胶片质感 → 情绪关键词。
4. 展示完整提示词，等用户确认后生成。
5. 生成后按清单审核并交付。

## 质量审核清单
- 未改动用户场景内容
- 风格锚点全部包含且与用户所选色调一致
- 无品牌、真实人物、未确认元素
- 情绪词与孤独基调一致
- 多镜头间风格连续
- 输出无占位符与生产标记

## 失败处理
- 风格感弱：重复镜头与胶片质感锚点。
- 色调跑偏：在提示词首尾各锁一次色板。
- 用户场景与风格冲突：提示用户二选一，不擅自混合。
- 模型不支持某参数：删除该项并记录于已知限制。
- 连续失败：降级为提示词包交付，说明未生成原因。

## 交付
画布或文档交付：风格卡、最终提示词、生成资产、使用模型、审核结果、已知限制、下一步建议。
