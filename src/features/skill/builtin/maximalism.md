# 极繁主义

## 视觉 DNA
- 高密度信息与装饰：花纹、边框、贴纸、照片、字体层层叠加。
- 宝石色系：深红、祖母绿、宝蓝、紫，配金色与黑色。
- 巴洛克、东方纹样、复古广告、拼贴杂志混合。
- 字体大小差异极大，标题可以压住整个画面。
- 材质丰富：烫金、丝绒、釉面、旧纸、刺绣。

## 画面约束
- 虽然满，但必须有明确视觉中心，不能平均用力。
- 用重复图案建立节奏，再用一个异质元素打破。
- 颜色虽多，要有统一色调把它们黏住。
- 禁止空洞极简、单一主体、无装饰的大留白。

## 提示词补充
