# Skill: 照片转高级极简矢量旅行海报

## 任务目标

将用户提供的一张照片，转化为一张 **premium minimalist flat-vector travel poster** 风格的场景化插画。  
不是机械描摹照片，而是从原图中提炼出最具代表性的主视觉焦点，并围绕它补充少量辅助元素，构建属于这个地方 / 对象 / 情境的独特氛围。

---

## 工作流程

### 1. 解析输入照片

- 识别照片中的核心对象、环境结构、光线、色彩与整体氛围。
- 提取照片中最具识别性的 **主体、轮廓、姿态与叙事关系**。
- 判断哪一部分最能够代表“这是这个地方 / 这个对象 / 这种情境”。

### 2. 确定主视觉焦点

- 在照片中提炼出一个清晰的、有代表性的主视觉焦点。
- 可以是：建筑局部、街道转角、一件静物、一组植物、一片光影、一个环境片断。
- 主体必须是第一视觉中心，所有构图元素围绕它展开。
- 根据主体本身的气质重新组织画面，而不是照搬照片构图。

### 3. 补充辅助元素

- 围绕主视觉焦点，补充 **2–4 个辅助元素**。
- 辅助元素用于说明环境气质、日常方式、地方感或生活状态。
- 可选：典型植物、路边长椅、小招牌、遮阳篷、自行车、小型家具、器物等。
- 辅助元素必须克制，仅用于强化“这里是哪里 / 这是怎样一种生活”，不喧宾夺主。
- 严禁拼贴式地标堆积、明信片式罗列和过度叙事。

### 4. 构图组织

- 根据原图自然转化为：街道、广场、岸边、庭院、通道、平台、植物场景、室内角落等环境片段。
- 建立明确的前、中、后层次，可以用色块层叠或几何形状遮挡完成。
- 保证适度留白，让画面有呼吸感。
- 整体视觉节奏安静、有序、有方向感。
- 天空、地面、墙面等大面积区域优先用平涂色块处理，保持简洁。

### 5. 人物设定（可选）

- 如果画面需要人物，仅保留 **3–6 个小尺度人物**。
- 人物应自然融入环境，作为比例参照与生活氛围的一部分。
- 不设单一主角。
- 人物用简单几何形状概括，不需要五官或复杂动态。

### 6. 风格与技法

- 最终画面为**高级极简扁平矢量插画**。
- 气质关键词：日系文具感、精品贴纸插画、现代 editorial travel branding。
- 造型语言：简洁几何形、柔和轮廓、统一线重、平涂色块、克制细节。
- 氛围：清新、安静、精致、当代。

#### 配色规范

- 主氛围色：浅粉蓝、雾蓝、天空蓝、空气感冷调蓝。
- 平衡色：象牙白、奶油白、浅米色、柔和灰绿、建筑中性色。
- 点缀色：仅允许少量 **dusty rose / muted blush**，用于花、服饰、小标识、遮阳篷或局部装饰。
- 整体色彩柔和、通透、略微去饱和。
- 以原图的综合色温为起点做统一调整，保持轻盈和谐。

### 7. 文字与排版

- 从原图的地点、对象名称、主题词、状态或氛围中提炼一个**简短标题**。
- 搭配一句简短、克制、有气质的 **tagline**。
- 文字置于画面留白充足处，不压过主视觉。
- 整体排版气质：understated、editorial、spacious、premium。
- 可以加入少量小字信息、坐标式注释或微型说明，使其像高级旅行品牌或精品明信片中的视觉标识，自然融入构图。
- 不使用过度装饰性字体，不强行覆盖画面。

---

## 负面清单

- 不要写实，不要机械描摹照片。
- 不要厚重阴影、水彩肌理、纸张纹理、复杂笔触、渐变。
- 不要拥挤背景、过多细节、拼贴式地标堆积。
- 不要过度叙事，辅助元素不能成为独立视觉主角。
- 不要出现过多人物，不要设置单一主角。

---

## 输出要求

- 输出为高完成度的 SVG / PNG 图像，或对应的矢量格式。
- 如果只能输出文本，则应提供：场景描述、配色方案、构图说明、文字内容提案。
- 所有视觉决策必须遵循上述风格规范，保持克制、安静、精致。
