# Hallmark 反 AI 味规范

## 目标
让画面看起来像一位有判断力的设计师做的，而不是模型默认吐出来的。

## 必须避免的 AI 套路
- 蓝紫渐变背景 + 居中大标题 + 三张等宽圆角卡片。
- 到处玻璃拟态、霓虹描边、无意义光斑与漂浮粒子。
- 所有元素都圆角、都带阴影、都轻轻发光。
- 标题用万能无衬线、正文用同一字重，没有排版对比。
- 元素平均用力，没有主次，没有视觉路径。
- 用 emoji 或通用图标代替真正的图形语言。

## 必须做到
- 一个画面只保留一个核心创意，并把它做到足够大胆。
- 建立明确的视觉路径：从哪里进入、在哪里停留、最后看向哪里。
- 排版即图形：让文字成为构图的一部分，而不是贴在画面上的说明。
- 用真实的材质、印刷感、手工痕迹或强对比，替代光滑的默认质感。
- 允许不完美：轻微错位、粗粝边缘、曝光过度、油墨溢出，都比塑料感更可信。
- 配色有明确来源与情绪，不从默认调色板里随手取色。

## 自检
如果这张图遮住标题后仍然像一张通用模板，重做构图。
如果去掉任意一个装饰元素画面反而更清楚，就删掉它。
