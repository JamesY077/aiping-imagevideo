# Vaporwave

## 视觉 DNA
- 粉、紫、青、品红渐变，配深蓝或黑色背景。
- 网格地平线、落日、棕榈树、罗马石膏像、旧电脑窗口。
- 扫描线、色差、噪点、VHS 失真、日文/英文混排。
- 元素悬浮、重复、略微错位，营造梦境感。
- 字体可用衬线、像素或拉伸无衬线。

## 画面约束
- 至少一个标志性元素：网格地平线 / 石膏像 / 棕榈 / 落日。
- 渐变要服务于空间纵深，不要整屏糊成一片。
- 保留一点低保真噪点，避免过于干净的现代感。
- 禁止写实商业摄影、极简白底、粗野主义。

## 提示词补充
