# 卡带未来主义

## 视觉 DNA
- 1970-1980 年代消费电子：米色/灰色塑料、木纹、金属拉丝。
- CRT 屏幕、荧光绿或琥珀色字符、扫描线、旋钮、推子、磁带。
- 技术图纸网格、编号、刻度、警告标签。
- 配色偏暖旧：米灰、棕、橙、荧光绿、深黑。
- 字体像设备丝印：等宽、无衬线、全大写。

## 画面约束
- 画面要像一台真实存在过的旧机器，有使用痕迹与磨损。
- 至少出现一个模拟界面或物理控件（屏幕 / 旋钮 / 磁带 / 开关）。
- 光线偏暗，靠屏幕与指示灯发光。
- 禁止现代扁平 UI、玻璃拟态、蓝紫渐变、极简白底。

## 提示词补充
cassette futurism, 1970s analog technology, beige plastic, CRT screen, cassette tapes, knobs and dials, amber and green phosphor glow, technical grid, retrofuturist interface
