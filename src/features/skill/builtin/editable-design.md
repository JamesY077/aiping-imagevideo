# Editable Design 固定画布规范

## 核心方法
把画面当成一张已经定好尺寸的海报画布，而不是一张随意生成的插画。
先在脑中分层，再开始画：
1. 背景层：底色、纸张、光影或环境。
2. 主体层：一个明确的主角，占据画面 35%-60%。
3. 文字层：标题、副标题、少量注释，形成清晰层级。
4. 装饰层：只放能强化主题的图形、线条、材质。
5. 留白层：主动留出呼吸区，不要让每个角落都被填满。

## 版式约束
- 固定画布，构图完整，不出现被裁断的主体或半截文字。
- 四边留出安全边距，重要信息不贴边。
- 标题、主体、辅助信息形成稳定的三角或轴线关系。
- 文字与图形不互相打架；文字压图时必须保证对比度。
- 同一画面最多使用两种字体气质、三种主色。
- 装饰元素必须服务于主题，不能只是填空。

## 交付标准
画面应当像一张可以直接印刷或直接发布的成品：边缘干净、层级明确、主体突出、细节完整。
