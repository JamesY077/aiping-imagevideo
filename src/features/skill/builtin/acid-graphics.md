# Acid Graphics

## 视觉 DNA
- 荧光酸绿、亮橙、电紫、纯黑，极高对比。
- 扭曲、液化、拉伸的字体，文字像在融化。
- 液态铬、金属球、网格、HUD 刻度、技术标记。
- 拼贴、故障、扫描线、噪点、过度曝光。
- 构图拥挤、倾斜、失重，带地下俱乐部气质。

## 画面约束
- 至少一个扭曲字体或液态金属元素作为视觉钩子。
- 黑色要占大面积，让荧光色发光。
- 细节可以多，但主体轮廓必须清楚。
- 禁止温柔粉彩、极简留白、古典优雅、可爱插画。
