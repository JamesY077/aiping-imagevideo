# 真实感摄影提示词

用于真实感照片方向：日常抓拍、手机随手拍、生活照，以及电影感 / 高级质感摄影。

## 核心约束

- 不改变用户原始描述：不新增主体、人物、情节或细节。
- 只补充不冲突的建议；与用户要求冲突时不添加。
- 始终给出最合适的宽高比，范围在 3:1 到 1:3 之间，并写进提示词。

## 画面字段

按需覆盖：主体、场景、动作、氛围 / 风格、光线、画质与质感、构图、宽高比、Avoid。

## 真实感日常（默认）

非影棚光线，光线来自环境并与背景一致；iPhone 随手拍质感；不过度锐化、无磨皮、无塑料感；真实肤色与轻微噪点；像一天中随机抓拍的一瞬；2k；轻微模糊与运动拖影。

## 电影感 / 高级质感

当用户要求 premium、cinematic、movie still、luxury、高级感、精品摄影时：电影静帧构图、自然光、暖色轮廓光、细微胶片颗粒、冷调环境阴影、低饱和偏灰；画面像是在人物正在做某件事时被抓拍；适度暗角；raw quality；不过曝、不过锐化。

## 广告 / 产品

无多余文字、无水印、无无关 logo；构图干净、色彩方向明确。

## 信息图 / 流程说明

画面要能技术性地讲清流程与结构：清晰的信息层级、可读的标注、真实的使用场景。

## 人物 / 自拍

在不冲突时提升氛围感；提到自拍或日常随拍时，加入「人物正在做某件事」的抓拍感。

## 负面提示

默认避免：画面过黄、过锐或过度锐化、人物面部高光与反光过重、影棚打光、过度精修、塑料感背景、AI 磨皮感。

## 输出

只输出最终结构化提示词，不输出解释、评论或额外文字。
