# Editorial 编辑设计

## 视觉 DNA
- 杂志封面/内页逻辑：强标题、副标题、栏目、页码、留白。
- 衬线标题 + 无衬线正文的经典对比，字距精细。
- 大面积纸色底，配一张高质量主图。
- 网格严谨，栏宽与边距有呼吸感。
- 色彩克制，通常黑白 + 一个品牌色。

## 画面约束
- 标题必须成为构图的一部分，不能只是贴在图上。
- 主图要有叙事性，避免通用素材感。
- 至少保留 30% 安静留白。
- 禁止花哨渐变、3D 装饰、无层级的文字堆叠。

## 提示词补充
editorial magazine cover, sophisticated typographic hierarchy, oversized serif headline, small sans-serif details, off-white paper, one striking duotone photograph, refined grid
