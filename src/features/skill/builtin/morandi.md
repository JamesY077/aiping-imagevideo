# 莫兰迪

## 视觉 DNA
- 低饱和灰调：灰粉、灰绿、雾蓝、燕麦、灰褐、烟紫。
- 所有颜色都像掺了灰，明度接近，对比柔和。
- 哑光质感：粉笔、蛋壳漆、未上釉陶土、棉麻。
- 构图安静、稳定，主体少而精，边缘柔和。
- 字体细而优雅，衬线或无衬线皆可，字距舒展。

## 画面约束
- 画面不要出现纯黑纯白，用深灰与米白替代。
- 颜色数量控制在 3-4 个，面积均匀但不呆板。
- 光影柔和，不要强反光、霓虹、金属高光。
- 禁止高饱和撞色、强对比、夸张动态、复杂图案。

## 提示词补充
Morandi color palette, muted dusty tones, low saturation, matte gouache texture, soft diffused light, quiet still life, elegant restrained composition
