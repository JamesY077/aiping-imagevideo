# ArtRealm AI — AI 创作工作台

## 项目背景

ArtRealm AI 是一个面向 AI 图片与视频创作的轻量级工作台，基于 ArtRealm AI / AIPing 兼容 API 构建。

项目希望把不同图像、视频生成模型统一到一个简洁的创作界面中，让用户可以通过同一套流程完成文生图、图生图、文生视频、图生视频等创作任务，并在本地保存常用配置与生成记录。

## 功能

- **图片生成**：支持文生图、图生图，以及部分模型的图片编辑能力。
- **视频生成**：支持文生视频、图生视频，覆盖多种主流视频生成模型。
- **多模型切换**：可按创作类型选择不同模型，并根据模型能力展示可用输入方式。
- **素材上传**：支持上传本地图片或视频作为参考素材，用于图生图、图生视频等场景。
- **比例选择**：提供多种常用画面比例，适配横图、方图、竖图等创作需求。
- **对话式创作记录**：以聊天流形式展示提示词、生成状态和最终结果，便于回看与再次生成。
- **用量与费用展示**：记录生成调用次数和累计消耗，方便了解使用情况。
- **API 配置管理**：支持配置 Base URL 与 API Key，并可在设置页随时修改。
- **本地偏好保存**：自动保存媒体类型、模型、比例等常用选择，提升连续创作体验。

- Doubao Seedream 5.0 Lite

### 视频模型

- Vidu Q3 Pro / Q3 Pro Fast
- MiniMax Hailuo 2.3
- Kling Video O1
- Kling V3 Omni
- Kling V3
- Kling V2.6

## 使用说明

1. 启动项目后，先在配置页填写 API Base URL 和 API Key。
2. 进入创作页，选择图片或视频创作类型。
3. 根据需求选择模型、画面比例，并输入提示词。
4. 如模型支持参考素材，可上传本地图片或视频。
5. 点击生成后，在对话流中查看生成进度、结果和历史记录。
6. 如需调整接口地址或密钥，可在设置页重新配置。
